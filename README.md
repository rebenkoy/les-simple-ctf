# les-simple-ctf — challenge source

The intentionally vulnerable services for the **vuln-services** CTF course. This is the
sanitized source students are meant to read while attacking each running service.

> ⚠️ These services are deliberately insecure and meant to be run **on `localhost` only**,
> never exposed to a public network.

- One directory per challenge (its `id`, except the two forensics dirs
  `sniff-http-secretstore` and `sni-hidden-vault`).
- **No flags or answers here.** Each service reads its flag from the `FLAG` environment
  variable at runtime; the values live in the course's private secret store, not in this repo.
- **No packet captures here.** The forensics `.pcap` handouts are generated by the private
  solutions repo's builders and served by the hub — never committed (they carry the sniffable
  answer).

Run these through the platform repo
([`hallucinated-ctf-platform-`](https://github.com/rebenkoy/hallucinated-ctf-platform-)):
clone this repo into its `challenges/` directory, then `just challenge <id>`.
