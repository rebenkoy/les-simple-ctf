Secrets Storage v1

Your private notes live behind a small JSON API. It only reveals them when the request carries your signed-in session — but it's built to let partner apps integrate from other origins.

API
GET /api/account   →  {"user", "email", "secret_note"}

secret_note is returned only with a valid session cookie. To support partner apps, every response echoes your Origin back in Access-Control-Allow-Origin and sets Access-Control-Allow-Credentials: true.
